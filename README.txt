DUX-6 - PROTOTYPE INTERAKTIF
PT Eclo Mega Nusantara

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Klik dua kali index.html untuk membuka di Chrome/Edge.
3. Pada halaman login, isi username dan password apa saja (simulasi, bukan autentikasi asli).
4. Coba menu Dashboard, Data Barang, Barang Masuk, Barang Keluar, dan Laporan Persediaan.
5. Data contoh disimpan di localStorage browser, bukan server atau database perusahaan.

FITUR
- Navigasi dan login demo
- Tambah, edit, hapus data barang
- Catat barang masuk dan keluar dengan validasi stok
- Dashboard ringkasan stok
- Laporan dan ekspor CSV, cetak/simpan PDF melalui browser

BATASAN
Prototype untuk keperluan pembelajaran UI/UX. Tidak aman digunakan sebagai sistem produksi. Tidak memiliki backend, akun nyata, atau database terpusat.
